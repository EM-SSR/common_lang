# 多モーダル層（Multimodal.hs）

仕様: 05_多モーダル文法.md

## 観測射と復元（定理1.1）

意味は C 側に置かれる。四つのモーダル観測射 f_m:C→R_m と復元 p_m を実装し、
`p_m(f_m(C)) ≅ C` を全モーダルで検証する:

| モーダル | 観測 | 復元 |
|---|---|---|
| R_text | `fText` = ser 文字列 | `pText` |
| R_glyph | 装飾文字列 W[…] | `pGlyph` |
| R_image | 層を走査帯、箱を領域 (位置,幅,文字) として配置 | `pImage` |
| R_audio | 層ごとの発音グループ（構文境界＝グループ分割） | `pAudio` |

定理1.1 の検証: 四モーダル全てが同じ CNF へ復元すること、および
image と audio の復元結果が相互に一致すること。画像を文章へ翻訳してから
音声へ、という経路は不要——共通の意味対象を介して読む。

## 単射性の負検証

正の往復テストだけでは単射性の破綻を見落とすため、二つの負検証を置いた:

1. 異なるチェンバーは異なる画像へ観測される（`fImage c₁ ≠ fImage c₂`）
2. 画像上の概念文字を一つ破壊すると、復元が失敗するか別物になる

## 画像の領域と ∂

画像の各行は層であり、各要素は「領域」としての箱: 位置 q・幅・概念文字。
幅は描画情報ではなくポート列の長さから復元される。復元後のチェンバーは
`runPorts` による整形式検査を通らなければならない。

## 実装詳細

1. R_audio は frontier 走査により隙間を無声音 "_" へ写す。恒等ワイヤのみの
   区間も意味をもつ音素列になり、復元では "_" がワイヤ一本の通過として読まれる。
2. 画素レベル: ImgFn（座標 → 色成分の有限関数）、regionBoundary（∂G:
   4 近傍に非所属セルを持つセル列）、relativeAddress（平行移動不変な相対アドレス）
   を実装し、領域文法の原始を提供する。
