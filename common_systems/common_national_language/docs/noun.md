# 名詞層の API と意味論

仕様は `docs/common_national_language/07_名詞と影響ネットワーク.md`。対応モジュールは
`src/noun/NounNet.hs` と `src/noun/Metanoun.hs`。残差と整合対の土台は
`counter_plane` 側の `GclsCategory` にある。

## NounNet.hs

| 数式 | 実装 | 出典 |
|---|---|---|
| 影響対象 𝐆 = (G, L, w) | `Landmark`, `Node`, `Individual` | §2 |
| プロファイル x̂ | `profileOf` | 定義1.2 |
| 整合 ◁（Σλ = 𝟏、λ ≥ 0） | `compatible` | 圏論 定義1.3 |
| 関係語の適用 f_u(x) | `applyWord`（右側への ★ 積。適用順が意味を持つ） | 例5.1 |
| 挙動 beh_μ(x)(u) = F_μ(w(ℓ, f_u(x))) | `behProfile` | §3.4 |
| Nerode 合同 x ≈μ y | `nerodeEqUpTo k μ L x y` | §3.4、命題3.1 |
| 記憶深度の読み F_μ | `gradeOf`（∞/2 は全情報、1 は π、0 は Θ∘π） | 定義3.4 |

個体には二つの入口がある。

- `RelNode x` — 関係語で到達する離散状態。重みは Kronecker 型（x = ℓ なら 𝟏）。
- `Observed ps` — 観測射がタレス比として供給したプロファイル。座標を外から割り当てない（§10.5）。

`nerodeEqUpTo` は継続語を長さ k までの snf 代表元に限る。遷移モノイド
⟨i,j | i²=σ, j²=e⟩ は無限なので全継続の直接列挙は停止しない。
分離（≈でない）は有限の証拠語で確定する。肯定側の完全判定が必要になったら
状態の周期性検出を足す。

## 全名詞の列挙

`tools/DumpNounCsv.ps1` が、現状の実装で表現可能な名詞を機械的に列挙し
`builds/nouns.csv` へ書き出す。テスト専用の Haskell エントリポイントは作らず、
既存のデモランナー `src/spec/PhraseDemo.hs`（例文 6）の出力から抽出する。
列挙の実体は `Metanoun.nounCsvLines`。

- `relnode` … 原始関係語（長さ `nounKmax` までの snf 代表元）が原点 O から
  到達できる離散状態すべて。遷移モノイドは無限なので列挙は深さで打ち切る
- `observed` … 観測射が供給したプロファイル。例2.1 の見本を一行だけ載せる
- `concrete` … メタ名詞に所属する個体への呼称。所属する組だけ行を持つ

各列はコモン公用語そのもの: 語の記述は `ser(C)`、発音は `E_speech`
（空本体は零標示音）、呼称は採用語彙 `V^ext`、プロファイルと判定値は 𝒬 の大きさ。
零除算の拡張（0⊘0=1、x⊘0=0）は `GclsCategory.thalesDivR` のコメントを参照。

## GclsCategory への追記（counter_plane 側）

| 数式 | 実装 | 出典 |
|---|---|---|
| 残差 a ⇘ c = min(1, c ⊘ a)、c ⇙ b = min(1, c ⊘ b) | `residualRightQ`, `residualLeftQ` | 07 §1、例1.2 |
| 整合対 (q ⇔ p) = (q⇘p) ⋆ (p⇙q) | `agreeQ` | 07 §6.2、定義10.2 |
| 大きさの有理数表現 | `QRat`（既約化しない。比較は交差乗算 `qratEq`） | 二進比の商が二進比にならないため |

零除算の扱い: 比較の形がそのまま 0⊘0 = 1、x⊘0 = 1、0⊘x = 0 を与える。
例10.7 の原型 p̂ = (0,0,1) のように零成分を含む原型の判定に必要になる。

## 観測射と文接続

- 観測射（§10.5）: 一つの観測から二つの表示が出る。画像モーダル（05）が
  領域を記述チェンバーへ読み（発音可能）、6c の重心座標 λ が影響プロファイルを
  供給する（判定可能）。`Observation` / `observeFromRegion` / `nounifyOnT1`。
  座標系の値を外から割り当てない
- 文への接続（§7）: 値層の名詞ノード型 `VNoun アドレス プロファイル`
  （ポート `PNoun`）。主語・目的語を名詞ワイヤ、述語を関係チェンバー
  `PRel 語` にすると、文 = (C_S ⊗ C_O); C_V が構成でき、
  関係語 u が主語ノードへ適用される。非可換なので適用順が意味を持つ。
  `SentenceGrammar.nounSentence`
- 土台（§8.2、§8.3、§8.4）: 参照 `#k` は `CommonChamber.refC`（ser 昇順の位置）、
  Δ_A は `dupNC`／`PDupN`、!_A は `dropNC`／`PDropN`。
  μ=∞ のノードは複製できない（無断複製の禁止、構成語 §3.5）。
  Ω 閉包は `POmW 語`（周期軌道を入口の状態へ一段で閉じる。不動点ならその値。
  境界まで閉じない軌道には値を与えない＝整形式でない）

## 任意の名詞のチェンバー化

三つの名詞形がすべて第一級の意味対象＝Chamber へ持ち上がる（`AnyNoun` /
`nounChamberOf`）。

| 名詞形 | 意味対象チェンバー |
|---|---|
| 関係ノード `NNode 語` | 語を実行する原始文字の逐次合成（空語は零標示音） |
| メタ名詞 `NMeta m` | 判定チェンバー `judgeChamberM` |
| 具体名詞 `NConc cn` | 個体の記述チェンバー |

判定チェンバーはメタ名詞ごとに固有の正準形を持つ（定理10.4）。離散ノードの
原型は one-hot プロファイルなので、成分ごとに整合対の特殊形
`PAgrU`（p_ℓ=𝟏）/ `PAgrZ`(p_ℓ=0) を焼き込む。𝟏 と 0 は quantale の
原始値であり、定数の新設には当たらない。

実行値は `Metanoun.memberOf`（関数版）と一致することをセルフチェックで常時
検査する（二実装の意味論一致）。

天井: 分数の原型（観測から来る内部点）は定数原始が存在しないため焼き込めず、
`judgeChamberM` は Nothing を返す。そうした概念の判定は関数版 `judgeMeta` か、
原型を入力ワイヤで受ける構成を使う。

## 呼称の一意性と同期（06 §17 の運用意味論）

- **一意性**: 採用表は入力（聴取チャネル、削除・挿入ペナルティ、閾値 ε、
  頻度レコード）から決定的に計算される（命題17.5）。同じ入力なら誰が
  計算しても同じ表になる
- **依存の対象**: 会話の文脈には依存しない。依存するのは語彙集合 C₀ と
  測定された頻度 ρ、すなわちコミュニティが共有する辞書の版である。
  上位語彙の追加は表の改訂（新版の配布）を意味し、低頻度の追記は
  既存の割当てを変えない（版の安定性テスト）
- **同期**: 対話ごとのネゴシエーションは不要。両者が同じ版の表を参照する。
  単射性の強化により採用列は全意味の基準列と絶対に一致しないため、
  古い版しか持たない聴取者は誤復号ではなく復号失敗になる（検出可能）。
  話者は基準発音 pron で再話すればよく、V^ext の基準フォールバックが
  グレースフルデグラデーションを与える
- **構造予約**: 零標示音 z_e は採用対象から外す。改名されると §16.2 の
  正準割当てが死ぬためである
