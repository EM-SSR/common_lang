# 文法層（SparseTensor.hs / SentenceGrammar.hs）

仕様: 02_三次元疎テンソルと文法.md

## 三次元疎テンソル S(k,q,r)

| 軸 | 意味 | 実装上の所在 |
|---|---|---|
| k | 文章中の語位置 | `sentenceEntries` の第1成分 |
| q | その深さでの frontier 位置 | 層内の箱の左端位置 |
| r | 語内部の因果深度 | 最大平行層の層番号 |

```haskell
entries         :: Chamber -> [((Int,Int), String)]        -- 一語分
sentenceEntries :: [Chamber] -> [((Int,Int,Int), String)]  -- 文章分
depthOf         :: (Int,Int) -> Int                        -- 因果深度 = 層番号
```

因果深度は前駆関係から導かれ、最大平行層では `v ∈ Λ_r ⟺ h(v) = r` が
そのまま成り立つ。したがって深さを別途計算する必要はない。

箱のない位置には値を置かない。定義域は ragged であり、
`portFrontierSeqM` の返す frontier 列が深さごとの幅変化を正確に追う
（例: add 箱は二本の座標ワイヤを一本へ畳むので幅 2 → 1）。

## 復元定理（定理6.1）

```haskell
restore :: Mu -> Int -> [Port] -> [Port]
        -> [((Int,Int), String)] -> Maybe Chamber
```

原始文字辞書 `primitiveTable` を使い、(r, q) 昇順に層を組み立て直す。
検証コードは二段で確認する:

1. **構造的復元**: `restore (entries c) == Just c`
2. **意味論的復元**: 復元した語の実行結果が元の語と完全に一致する

第二段が重要である。疎テンソルは表示上の装飾ではなく、
「積み上げた演算への参照」を可逆に並べ替えたものだから、
復元後に走るのは counter_plane の同じ実装である。

備考: 原始文字辞書に無い概念文字（例: "cow"）は復元に失敗する。
牛を扱えるようになるには、まず牛の構成が counter_plane 側で
原始文字の合成として確立しなければならない——仕様どおりの順序である。

## SOV は導出される（命題9.1）

```haskell
readingOrder :: Chamber -> [String]   -- (r, q) 昇順にタグを読む
sovSentence  :: Maybe Chamber         -- (C_S ⊗ C_O); C_V
```

- 主語 S・目的語 O は第0層に並ぶ（互いに独立＝テンソル積）。
- 述語 V は第1層にある（S と O の出力を入力として必要とする＝逐次接続）。
- `(r, q)` の昇順に読むと自然に S O V になる。

SOV を公理として置いていないことを、この構成自体が示している。

述語の中身は飾りではない。`atomV = mkAtom "V" PAdd` であり、
PAdd は DagArith.addS——四則演算層の加算そのものである。したがって:

```
ghci> evalChamber sovSentence [VCoord (2,4,3), VCoord (1,6,3)]
Just [VCoord (3,10,3)]
```

という文の実行が、直接の `addS` 呼び出しと一致することまで検証してある。

## 単語境界は意味論の原始ではない（命題11.1）

語の区切りに表示上の印（`|`）を挿入しても、パース後のチェンバーは同じであり
意味は変わらない。形態素境界はレンダリング側の自由度である。

## 実装詳細

1. restore は原始文字レジストリに依存する。複合語（原始文字の逐次合成）として表現されるため、
   単一の概念文字としては復元されない。これは仕様であり、複合語は構成履歴を保持することで
   区別される。
2. readingOrder は層内の左右順序を表示順として採用する規約であり、
   「時間的な先後」とは無関係である（§10 の分離）。逐次性が必要な場合は ; で組む。
3. 多モーダル成分（§6 の #k 参照）は Multimodal 層の完成により
   概念チェンバーの成分として構成可能になった（Ideogram.evaluateConcept 参照）。
